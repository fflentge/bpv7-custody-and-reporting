## Traceability Maintenance

When changing normative behavior:

1. Record the source section or requirement.
2. Identify the target draft and section anchor.
3. Note whether the text is retained, rewritten, split, or intentionally
omitted.
4. Record the rationale for any semantic change.
5. Check whether the same concept is referenced by either companion draft.
